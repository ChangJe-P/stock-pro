# 주몽 가상계좌·현금 원장

## 목적

단일 로컬 사용자의 가상 현금과 거래 가정을 안전하게 시작하고, 이후 주문·체결 기능이 참조할 수 있는 변경 이력을 남긴다.

## 범위와 경계

- 가상 현금만 사용한다. 실제 증권 계좌, 계좌번호, 잔고 조회, 실주문, 자동매매는 구현하지 않는다.
- 최초 가상 현금과 수수료·세금·슬리피지 가정은 backend 설정 계층에서만 읽는다. 값은 비밀값이 아니지만 서비스 코드에 직접 적지 않는다.
- 계좌를 최초 생성할 때 적용된 가정은 계좌에 스냅샷으로 보관한다. 이후 로컬 설정을 바꿔도 기존 계좌·원장 해석이 바뀌면 안 된다.
- 현금 원장은 추가만 가능하다. 기존 원장 행의 수정·삭제·초기화 API를 만들지 않는다.
- 현재 현금은 최초 현금과 원장 금액의 합으로 계산한다. 별도의 잔액을 임의로 갱신해 원장과 불일치하게 만들지 않는다.

## 구현 전 확인

- 작업 문서에 최초 현금, 수수료·세금·슬리피지 가정과 정책 버전이 명시돼 있는지 확인한다.
- 현재 브랜치와 작업 문서의 브랜치가 같은지 확인한다.
- 기존 backend 설정 계층과 T-002의 재실행 안전한 PostgreSQL 초기화 방식을 재사용한다.

## 검증

- 최초 초기화가 원장 시작 행을 정확히 한 번 만들고, 반복 초기화가 현금을 재설정하지 않는지 확인한다.
- 설정 누락·음수 금액·허용 범위를 벗어난 비율은 안전하게 실패하며 값 자체를 응답·로그에 노출하지 않는지 확인한다.
- mock 테스트, 실제 PostgreSQL 확인, 실제 시장 데이터 확인을 서로 다른 증거로 기록한다.

## 제외

- 주문 예약, 다음 거래일 시가 체결, 보유 수량, 실현·평가 손익, 종목 가격 조회, frontend, Notion 연동은 별도 작업으로 남긴다.
