# T-007 가상투자 시작과 일봉 수동 준비 화면

## 목표

브라우저에서 주몽의 가상 학습 계좌 상태를 확인하고, 계좌가 없을 때만 최초 계좌를 만들며, 사용자가 지정한 국내 종목 한 개와 기간의 일봉을 **명시적으로 요청했을 때만** 수집할 수 있게 한다.

현재 결정된 시작 가상 현금은 **10,000,000 KRW**다. 이 값은 `VIRTUAL_INITIAL_CASH_KRW` 설정과 계좌 최초 생성 시 저장되는 정책 스냅샷에서만 읽는다. 화면이나 서비스 코드에 숫자를 직접 적지 않는다.

## 사용자 흐름

```text
GET /setup
  ├─ 계좌 없음: 현재 정책의 시작 현금 안내 → [가상 학습 계좌 시작] POST
  ├─ 계좌 있음: 최초 현금·가용 현금·정책 버전 안내 (재설정 버튼 없음)
  └─ 일봉 수동 수집: 종목 코드·시작일·종료일 입력 → [일봉 수집] POST
       └─ 성공: 수집 실행 결과를 다시 GET 화면에서 확인
```

- 계좌가 없더라도 일봉 수집은 가능하다. 가격 데이터는 계좌와 독립된 학습 재료이기 때문이다.
- 계좌 생성과 일봉 수집은 `GET /setup`, `GET /`에서 절대 자동으로 시작하지 않는다.
- 수집 후에도 주문 생성·주문 체결·현금 원장 추가·대시보드 평가를 자동으로 시작하지 않는다.

## 구현 범위

### 1. Django Template 화면과 URL

아래 HTML 경로를 추가한다. 기존 JSON API의 경로·상태 코드·응답 본문은 변경하지 않는다.

| 메서드·경로 | 역할 |
|---|---|
| `GET /setup` | 읽기 전용 시작·데이터 준비 화면 |
| `POST /setup/account/initialize` | 최초 가상계좌 생성 요청 |
| `POST /setup/market-data/collect` | 사용자가 입력한 한 종목·기간의 일봉 수집 요청 |

- `GET /setup`은 `VirtualAccount`, 기존 수집 실행 기록, 필요한 경우 검증된 정책 설정만 읽는다. 계좌·원장·주문·가격 행을 만들거나 pykrx를 호출하지 않는다.
- 기존 `accounts.initialize_account()`과 `market_data.collect_daily_prices()`를 재사용한다. 같은 규칙을 새로 구현하거나 별도 제공처·서비스 추상화를 만들지 않는다.
- HTML form에는 Django `{% csrf_token %}`을 사용한다. 기존 JSON API의 `csrf_exempt` 동작을 바꾸지 않는다.
- 계좌 생성 성공 뒤에는 `303 See Other`로 `GET /setup`에 이동한다. 새로고침으로 POST가 반복되지 않게 한다.
- 일봉 수집 성공 뒤에는 `303 See Other`로 `GET /setup?collection_run=<run_id>`에 이동한다. 이 GET은 기존 `MarketDataCollectionRun`의 해당 실행 기록을 읽어 수집 결과를 표시하며 외부 수집을 시작하지 않는다.
- 존재하지 않거나 형식이 잘못된 `collection_run`은 수집·DB 쓰기 없이 안전한 안내로 처리한다.

### 2. 가상계좌 상태

- 계좌가 없으면, backend 설정 계층의 유효한 정책에서 읽은 시작 현금·정책 버전·학습용 가정이라는 점을 보여 준다. 정책 설정이 유효하지 않으면 초기화 버튼을 감추고 안전한 설정 오류 안내만 표시한다.
- 계좌가 있으면 `VirtualAccount`와 원장 합계로 계산한 가용 현금, 최초 가상 현금, 정책 버전을 보여 준다.
- `POST /setup/account/initialize`은 기존 one-time 초기화 규칙을 그대로 사용한다. 이미 계좌가 있으면 기존 계좌를 반환할 뿐, 현금·정책 스냅샷·원장을 변경하거나 추가하지 않는다.
- 시작 현금 수정 입력, 계좌 재설정, 원장 수정·삭제, 여러 계좌 선택 기능을 만들지 않는다. 나중에 새 학습 회차가 필요하면 별도 작업에서 명시적으로 설계한다.

### 3. 일봉 수동 수집 form

- 입력 항목은 `ticker`, `from_date`, `to_date` 세 개뿐이다.
- `ticker`는 숫자 여섯 자리, 날짜는 ISO 날짜이며 시작일은 종료일보다 늦을 수 없다. HTML 입력 제약은 보조 수단이고, 서버 검증은 기존 T-002와 같은 규칙으로 반드시 수행한다.
- 유효한 POST에서만 `MARKET_DATA_PROVIDER=pykrx` 설정을 확인하고 기존 pykrx 수집을 한 번 요청한다. 브라우저 접속·대시보드 접속·GET·페이지 새로고침으로 수집하지 않는다.
- 성공 화면에는 종목 코드, 요청 기간, 데이터 출처, 비조정 여부, 수집 기준 시각, 상태, 반환·삽입·갱신·제외 행 수, 제외 사유를 표시한다. 원본 응답 전문, 비밀값, 전체 연결 문자열은 표시·로그 기록하지 않는다.
- 잘못된 form 입력은 422 HTML 응답으로 같은 화면에 필드별 또는 전체 안전한 오류를 보여 주며 pykrx를 호출하지 않는다.
- `MARKET_DATA_PROVIDER` 설정 오류와 pykrx 조회 실패는 기존 안전한 의미를 유지해 HTML에서 구분해 보인다. 실제 네트워크가 실패했을 때 우회·재시도 루프·다른 데이터 제공처 호출을 하지 않는다.

### 4. 화면 원칙

- `docs/UI-DESIGN-REFERENCE.md`를 따른다. 알파스퀘어의 화면·문구·이미지·상표를 복제하지 않고, 정보 우선순위와 절제된 금융 대시보드 감각만 참고한다.
- 기존 Django Template과 `backend/trading/static/trading/dashboard.css`를 재사용·최소 확장한다. Django static CSS 외 새 프론트엔드 프레임워크, JavaScript, CDN, 외부 폰트·이미지, CSS·아이콘 library를 추가하지 않는다.
- semantic HTML의 `header`, `main`, `section`, heading, `form`, `label`, `input`, `button`, 상태 안내를 사용한다. 모든 입력에는 연결된 label과 설명·오류 안내가 있어야 한다.
- 가상 학습용 계좌, 실제 주문·실제 돈과 무관함, 수동 수집임, 가격 출처·기준 시각·KRW/주 단위를 분명히 표시한다.
- 375px, 768px, 1024px, 1440px에서 읽을 수 있게 한다. 작은 화면에서는 form과 결과 수치를 한 열로 쌓고, 핵심 행동 버튼과 오류를 가리지 않는다.
- 현재 작업에 실제 데이터가 없는 관심 종목 위젯, 차트, 주문 폼, 매도 버튼, AI 추천, 가짜 시세·가짜 알림을 만들지 않는다.

## 완료 기준

1. `GET /setup`은 계좌·수집 실행·주문·원장·가격 행을 쓰지 않고 pykrx를 호출하지 않는다.
2. 계좌가 없을 때 검증된 설정의 최초 현금·정책 버전과 CSRF 보호된 최초 생성 form을 보여 준다.
3. 계좌 생성 POST는 기존 one-time 초기화를 재사용하며, 반복 POST가 계좌·원장·정책 스냅샷·가용 현금을 재설정하지 않는다.
4. 계좌가 있으면 최초 현금·가용 현금·정책 버전을 보여 주고 재설정·수정 경로를 제공하지 않는다.
5. 일봉 수집 form은 ticker·기간을 서버에서 검증하고, 잘못된 입력에서 422 HTML 응답과 안전한 오류를 반환하며 외부 수집을 시작하지 않는다.
6. 유효한 수집 POST만 기존 pykrx 수집 함수를 한 번 호출하고, 성공 뒤 PRG 방식으로 수집 실행 결과를 읽기 전용 GET 화면에 표시한다.
7. 화면 결과는 출처·비조정 여부·수집 기준 시각·상태·반환/삽입/갱신/제외 행 수·제외 사유를 감추지 않는다.
8. 설정 오류·외부 조회 실패·DB 오류에서 비밀값·연결 문자열 없이 안전하게 안내하며, 다른 제공처·자동 재시도를 하지 않는다.
9. 기존 JSON API, `/health`, 대시보드 `GET /`의 읽기 전용 보장, T-001~T-006 동작이 유지된다.
10. Django 테스트, `python manage.py check`, `python manage.py makemigrations --check --dry-run`을 실행한다. mock 테스트·실제 Docker Compose 확인·실제 pykrx 네트워크 결과를 구분해 기록한다.
