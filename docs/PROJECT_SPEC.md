# 주몽 프로젝트 명세

## 제품 목표

주몽은 주식 초보자가 종목의 가격 흐름, 자신의 판단 근거, 가상 포트폴리오 성과를 함께 복기할 수 있게 돕는 국내 주식 학습 웹 서비스다.

## MVP의 고정 범위

- 가상 현금 기반의 단일 로컬 사용자
- 실제 시장 일봉 데이터 기반의 관심 종목과 종목 차트
- 다음 거래일 시가 기준의 가상 주문과 포지션·손익 계산
- 손실 한도 경고와 사용자의 유지·가상 매도·기준 변경 선택 기록
- 일일 투자 성과, 코드 리뷰, 개발 진행을 Notion으로 내보낼 수 있는 구조

## MVP 제외 범위

- 실제 증권 계좌 연결과 실제 주문
- 자동 매수·자동 매도
- 실시간·장중 가격 체결
- 출처나 이용 조건이 불명확한 대량 웹 크롤링
- 투자 수익 보장 또는 투자 자문

## 기술 방향

| 영역 | 선택 |
|---|---|
| 웹 애플리케이션 | Django와 Django Template (단일 서비스, 화면·JSON API 같은 origin) |
| 언어 | Python |
| 데이터베이스 | PostgreSQL |
| 실행 환경 | Docker Compose (`db`, `web`) |
| DB 확인 도구 | DBeaver |
| 배포 | 로컬 기반 MVP 안정화 후 AWS 검토 |

> T-005에서 기존 FastAPI backend와 Next.js frontend를 Django + Django Template 단일 서비스로 전환했다. JSON API 경로·상태 코드·응답 의미와 PostgreSQL 데이터는 그대로 유지한다.

## 시장 데이터와 손익의 원칙

- 종목 일일 등락률은 실제 일별 가격 데이터에서 계산한다.
- 계좌 수익률은 가상 보유 수량, 체결 시점, 수수료·세금·슬리피지 설정에 따라 종목 등락률과 다를 수 있다.
- 모든 데이터에는 출처와 기준 시각을 기록한다.
- 일봉 모드에서는 종가 확인 후 입력한 주문을 다음 거래일 시가에 체결한다. 이 규칙으로 미래 데이터 누수를 막는다.

## 협업 흐름

Codex가 작업 명세와 Skill을 준비하고 기능 브랜치를 만든다. Claude Code가 구현과 테스트를 마친 뒤 인수인계를 작성한다. Codex가 요구사항, Git diff, 테스트 결과를 검증한 뒤 다음 작업 또는 수정 요청을 결정한다.
